# 💬 Chat Básico Cliente-Servidor con Sockets y SQLite

Trabajo Práctico Obligatorio — Implementación de un servidor de sockets en Python
que recibe mensajes de clientes, los almacena en una base de datos SQLite y
responde con una confirmación. El cliente puede enviar múltiples mensajes hasta
que el usuario escriba `éxito`.

---

## 📌 Objetivo

Aprender a configurar un servidor de sockets en Python que:
- Reciba mensajes de clientes vía TCP.
- Almacene cada mensaje en una base de datos SQLite.
- Envíe confirmaciones al cliente.
- Aplique buenas prácticas de **modularización** y **manejo de errores**.
